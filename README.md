# Amazon Clone UI

A pixel-inspired Amazon UI clone built with **Next.js**, **React**, and **Tailwind CSS**.

This project focuses on recreating Amazon's interface as accurately as possible while practicing modern frontend development techniques. The goal is to build each component from scratch with responsive layouts, clean code, smooth interactions, and reusable components.

> **Note:** This is a frontend UI clone created for learning and portfolio purposes only. It is not affiliated with or endorsed by Amazon.

## 📦 Installation

Clone the repository:

```bash
git clone https://github.com/yourusername/amazon-clone-ui.git
```

Navigate to the project:

```bash
cd amazon-clone-ui
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```

Open your browser:

```
http://localhost:3000
```
